# Storage Lab Console — Tài liệu đã hợp nhất

**Cập nhật:** 09/10/2026.

Đặc tả UI/backend, OSD Info Collector, PA1/PA2, QoS, Lab Test và comparison của tài liệu này đã được hợp nhất vào **[kế hoạch Storage Lab Console v3.0](./code/plan(5).md)**.

Từ phiên bản này chỉ cập nhật kế hoạch chính; file này giữ liên kết tương thích cho các tài liệu đang trỏ tới đây, không còn backlog hoặc Definition of Done riêng.

| Nội dung trước đây | Vị trí trong kế hoạch hợp nhất |
|---|---|
| Scope, session và kiến trúc | Mục 1–6 |
| Inventory, collector và danh sách OSD được chọn trong plan | Mục 7, 18 và 20.5 |
| PA1/PA2, isolation, replica và rollback | Mục 8–12, 18.5 |
| QoS và Lab Test | Mục 13–14 |
| API, schema, UI và security | Mục 16–19 |
| Evidence và so sánh PA1–PA2 | Mục 20 |
| Lộ trình, tests, DoD và lát cắt tiếp theo | Mục 21–26 |
| Một OCI image ứng dụng, cấu hình runtime, lưu trữ bền vững và cài online/offline | Mục 28 |

Mục tiêu mới là đóng gói ứng dụng thành container image có thể đưa vào lab và tái sử dụng ở hệ thống khác bằng cấu hình. Đây là yêu cầu kế hoạch; chưa phải xác nhận image đã build, triển khai hoặc PA1/PA2 live đã đạt.
